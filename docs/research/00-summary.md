## 1. 結論(10 行)

1. **そのまま使える既存サービスは無い。** 「周囲の雑談を拾う」「iOS の画面ロック中も動き続ける」「ラフな口語を指定できる」の 3 つを同時に満たすものが見つからなかった(01)。
2. 近いのは AirPods ライブ翻訳(端末内処理、口調不可、対面向け)、Google 翻訳の聞き取りモード(一方向、iOS はロック中動作が未提供)、ChatGPT Voice(口調は指定できるが公式に「周囲の会話を無視する」設計)の 3 つ。
3. **音声→音声の一体型翻訳 API(OpenAI `gpt-realtime-translate`、Gemini Live Translate)は口調を指示できない**(公式明記、02)。「ラフな口語」を出すには、文字起こしのあとテキスト段で LLM に口調を指示する**分割型**が必要になる。
4. 視点 2 と視点 3 は同じ構成に収束した: **iPhone 内蔵マイクで集音 → 端末内 STT(Apple SpeechAnalyzer)→ 小型 LLM で口語訳 → TTS → AirPods(A2DP 出力専用)**。違いは LLM と TTS をクラウドに置くか(02)、Apple の Private Cloud Compute・自宅 Mac・端末内に置くか(03)だけ。
5. **AirPods のマイクは主入力にしない。** マイクを使うと Bluetooth が HFP に切り替わり、iOS 26 の高音質録音オプションもリアルタイム用途には非推奨と明記されている。Apple 自身もライブ翻訳で iPhone のマイク併用を案内している(02, 03)。
6. **最大の未知は「周囲 1〜3m の雑談を拾えるか」と「画面ロック中に 2 時間動き続けるか」**で、どの構成でも共通。最初の実機確認はこの 2 点に充てる。
7. 月額(月 60 時間、発話率 50% の仮定): 一体型 約 $61〜$132、分割型 約 $1〜$66(TTS の選択で決まる。LLM は月 $1〜$3)。端末内で完結させれば約 $1(02)。
8. 翻訳モデルの自作・追加学習は見合わない。日本語入力の同時音声翻訳のオープンモデルは非商用かつ GPU 前提のものしか無い(03)。
9. 進め方: まず既存サービスを実機で 30 分試して集音と遅延の感触を得る(費用ゼロ)→ 一体型 API で遅延の基準を取る → 分割型を Mac 上で組んで口語らしさを比べる → iOS ネイティブで連続稼働を確かめる。
10. ユーザーの判断が要る点は第 5 章。特に**学習言語**と**周囲の人の音声をクラウドに送ってよいか**で、選べる部品が変わる。

## 3. 推奨構成

```
周囲の雑談 ─▶ iPhone 内蔵マイク ─▶ VAD + STT(端末内 SpeechAnalyzer)
   ─▶ 小型 LLM(「友だち同士の口語で短く、訳だけ」)─▶ TTS ─▶ AirPods(A2DP、出力専用)
```

- 機種(iPhone SE 第 3 世代、Apple Intelligence 非対応)と判断(クラウド送信可、Mac 中継なし)により、各段の候補は次に絞られる(04)。
  - STT: `SpeechTranscriber`(ja-JP。SE 第 3 世代での動作は二次情報のみ)→ 不可なら `DictationTranscriber` → それも不可ならクラウド STT。
  - 口語化: **Claude**(Haiku 5.5 を既定、Sonnet 5.5 と聞き比べ)。端末内 Foundation Models と PCC は使えない。
    Translation framework の `lowLatency` はオフライン時・Claude 不通時の予備(口語にはならない)。
  - TTS: AVSpeechSynthesizer の enhanced / premium 音声($0)で始め、足りなければクラウド TTS。
  - 無音時の出力(要件追加): 周囲の発話が無い間は Claude が生成した学習言語の雑談を TTS で流す(内容の解釈は確認中)。
- 一体型 API(`gpt-realtime-translate`)は口語にならないので本命にはしないが、遅延と聞き心地の**基準**として最初に試す価値がある。

## 5. ユーザーの判断(2026-10-30 に決まったものと、残っているもの)

決まったもの(`../decisions/2026-10-30-initial-constraints.md`):

| 項目 | 判断 |
|---|---|
| 学習言語 | 英語・中国語・フランス語 |
| 周囲音のクラウド送信 | 許可 |
| 費用 | Claude API なら月 $50 まで(Haiku 5.5 で約 $1、Sonnet 5.5 で約 $17〜$35 の見込み。04 §2.8) |
| Mac 中継 | 採らない |
| 実機 | iPhone SE 第 3 世代。AirPods は型番の確認待ち(「4 Pro」という製品は無い) |
| 配布 | 予定なし |
| 無音時の出力 | 周囲に会話が無いときも出力する(内容の解釈は確認中) |

残っているもの:

1. **無音時の出力内容**。「Claude が生成した学習言語の雑談を流す」解釈でよいか。題材(場所・時間帯・直前の話題・固定テーマ)の希望。
2. **Claude 以外の費用(TTS)**。AVSpeechSynthesizer($0)で始めるか、クラウド TTS(Gemini Flash-Lite 約 $15/月、ElevenLabs 約 $65/月)を許容するか。
3. **AirPods の型番**(設定 > Bluetooth > AirPods の (i) で確認。04 §2.6 に型番の対応表)。主入力は iPhone マイクなので構成は変わらず、ANC の有無とマイク比較試験の範囲だけが変わる。
4. 口語化モデルを Haiku 5.5 既定にするか、最初から Sonnet 5.5 にするか(急ぎではない。聞き比べで決めてよい)。

## 6. 先行調査(prior-research.txt)の検証の要約

調査開始前にユーザーが置いた別 AI の調査結果(`prior-research.txt`、旧 `r.txt`)を 3 本のレポートで検証した。

- **確認できた**: GPT-Live の発表(2026-07-08)、iOS 版 Google 翻訳のロック中動作が「近日対応」、AirPods ライブ翻訳の対応言語 9 と iPhone 15 Pro 以降、`gpt-realtime-translate` の $0.034/分と出力 13 言語、一体型 API の指示不可、Hibiki-Zero の対応言語と非商用ライセンス、Foundation Models を翻訳に勧めない旨(WWDC25)、`bluetoothHighQualityRecording` の default モード限定。
- **訂正**: Galaxy AI 通訳は Galaxy Buds 必須ではない(スマホ単体で可、Buds は推奨)。
- **不足**: `bluetoothHighQualityRecording` は EU 非対応・入力遅延が増えリアルタイム通信に非推奨。`gpt-4o-mini-tts` は非推奨で 2027-01-06 停止予定。「端末内処理なら LLM 代だけ」の試算は TTS 費用(月 $15〜$65)が抜けている。
- **確認できなかった**: 「スペイン語ニュースで BGM が大きくなるまで問題なし」(出典とされた記事に該当記述なし)、各サービスの「数秒遅れ」(公式の数値なし)。
