# 2026-10-30 初期の制約と判断(ユーザー指示)

3 視点の調査(`docs/research/00-summary.md`)を受けて、ユーザーが下した判断。以降の設計はこれを前提にする。

| 項目 | 判断 | 影響 |
|---|---|---|
| 会話が無いときの出力 | 周囲に会話が無い状態でも出力があるようにする(目標に「外国語の雑談を聞けるようにする」が含まれるため) | 「周囲音の翻訳」に加え、無音時に流すコンテンツの生成・選択が要件に加わる。具体的な内容は確認中 |
| 学習言語 | 英語・中国語・フランス語をカバーできれば十分 | OpenAI の一体型(出力 13 言語)、Apple Translation、各 TTS の対応はこの 3 言語で確認すればよい |
| 周囲音のクラウド送信 | 許可 | クラウド STT・音声→音声 API も選択肢に残る。端末内 STT は必須ではなくなる |
| 費用 | Claude API なら月 50 ドルまで | 翻訳・口語化・無音時コンテンツ生成は Claude で賄う。Claude 以外(TTS 等)の費用の扱いは確認中 |
| Mac 中継 | 採らない | 視点 3 の Mac 構成(03 第 5 章)は対象外。処理は iPhone とクラウドで完結させる |
| 実機 | iPhone SE(第 3 世代)、AirPods「4 Pro」(ユーザー申告。型番は未確認) | SE 第 3 世代は Apple Intelligence 非対応。Foundation Models / PCC / AirPods ライブ翻訳(iPhone 15 Pro 以降)は使えない。SpeechAnalyzer 等の iOS 26 機能の可否は `docs/research/04-device-constraints.md` で確認 |
| 配布 | 予定なし(個人利用) | App Store 審査・PCC 申請・第三者の個人情報の扱いは個人利用の範囲で考えればよい |
